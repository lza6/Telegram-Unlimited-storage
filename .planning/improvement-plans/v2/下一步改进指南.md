## 2. 安全加固

### 2.1 [S-01] 下载签名密钥轮换支持

**当前状态**: `links.py` 使用单一 `DOWNLOAD_SIGNING_SECRET` 签名预签名 URL，无轮换机制。

**问题**: 密钥泄露后所有已签发 URL 立即失效，且无法平滑过渡。

**改进方案**:
```
实现密钥版本化：
- 配置支持 DOWNLOAD_SIGNING_SECRETS 逗号分隔多密钥
- 签名时使用最新密钥（active key）
- 验证时遍历所有密钥（包括已退役的）
- 支持通过环境变量热切换 active key
- 签名负载中增加 kid (key id) 字段
```

**验收标准**:
- [ ] 支持至少 3 个密钥共存（当前、上一个、上上个）
- [ ] 密钥切换后新 URL 使用新密钥，旧 URL 仍可验证
- [ ] 密钥泄露后可秒级切换

### 2.2 [S-02] API Key 最小权限体系

**当前状态**: 单一 API Key 拥有全部权限。

**改进方案**:
```
实现 API Key 权限范围：
- 在 tenants 表增加 scopes 字段 (JSON 数组)
- 支持: read, write, delete, share, admin, webdav
- 中间件层根据 scope 拒绝越权请求
- 默认新 key 为全部权限（向后兼容）
```

**验收标准**:
- [ ] 支持创建只读 API Key
- [ ] 无权限请求返回 403 Forbidden
- [ ] 管理页面可查看/编辑 Key 权限

### 2.3 [S-03] 请求体大小限制强化

**当前状态**: `config.py` 有 `max_upload_size_mb`，但 FastAPI 没有请求体大小中间件。

**改进方案**:
```python
# main.py 增加请求体大小限制中间件
from starlette.middleware import Middleware
from starlette.middleware.base import BaseHTTPMiddleware

class RequestSizeLimitMiddleware(BaseHTTPMiddleware):
    async def dispatch(self, request, call_next):
        if request.headers.get("content-length"):
            content_length = int(request.headers["content-length"])
            if content_length > max_size:
                return JSONResponse(status_code=413, ...)
        return await call_next(request)
```

**验收标准**:
- [ ] 超过限制的请求返回 413
- [ ] 不影响流式上传（分片模式）

### 2.4 [S-04] WebDAV Basic Auth 暴力破解防护

**当前状态**: WebDAV 的 Basic Auth 认证不受 `AccessGuard` 锁保护。

**改进方案**: 复用 `AccessGuard` 对 WebDAV Basic Auth 失败也计数。

**验收标准**:
- [ ] WebDAV 连续失败 8 次后锁定 300 秒
- [ ] 锁定后返回 429 Too Many Requests

## 3. 性能优化

### 3.1 [P-01] SQLite 连接池化

**当前状态**: `storage.py` 使用单连接 + `threading.RLock()`，所有数据库操作串行。

**问题**: 高并发时成为瓶颈，每个请求排队等待锁。

**改进方案**:
```
使用 aiosqlite 替代 sqlite3：
- 移除 threading.RLock，改用 asyncio.Lock 或连接池
- 或使用 sqlite3 的 WAL 模式 + 读并发（已启用 WAL）
- 读操作共享连接，写操作串行化
- 考虑引入 read-replica 模式（读从、写主）
```

**验收标准**:
- [ ] 并发读取吞吐量提升 3x+
- [ ] 写操作不受影响
- [ ] 所有现有测试通过

### 3.2 [P-02] 元数据缓存预热

**当前状态**: `metadata_cache` 表存在但缓存是冷启动，首次访问慢。

**改进方案**:
```
启动时预热缓存：
- 在 lifespan 中异步调用预热函数
- 预加载最近 1000 个文件元数据到缓存
- 使用 TTL 过期 + 后台刷新
- 可配置预热策略（全部/最近/按文件夹）
```

**验收标准**:
- [ ] 启动后首次文件列表请求 < 500ms
- [ ] 缓存命中率 > 90%
- [ ] 缓存预热不阻塞服务启动

### 3.3 [P-03] 大文件下载流式优化

**当前状态**: `downloads.py` 的 `_user_mode_stream` 使用 512KB part_size，对齐到 4096 字节。

**问题**: 512KB 对于大文件 (>1GB) 可能造成内存压力，小文件 (<1MB) 又不够高效。

**改进方案**:
```
动态分片大小：
- 文件 < 10MB: 使用 256KB parts
- 文件 10MB-100MB: 使用 512KB parts
- 文件 > 100MB: 使用 1MB parts
- 实现自适应算法根据下载速度动态调整
```

**验收标准**:
- [ ] 大文件下载内存峰值 < 50MB
- [ ] 小文件下载延迟 < 100ms
- [ ] 下载速度不低于当前基线

### 3.4 [P-04] Redis 集成（可选增强）

**当前状态**: `config.py` 已支持 `REDIS_URL` 和 `upload_queue_backend: "redis"`，但实际未接入。

**改进方案**:
```
Redis 接入点：
1. 上传队列后端（替代内存 ProgressBus）
2. 速率限制存储（替代内存 dict，支持多实例）
3. 会话缓存（替代 SQLite 的 metadata_cache）
4. 分布式锁（替代 asyncio.Lock，支持多 worker）
```

**验收标准**:
- [ ] Redis 不可用时自动降级到内存模式
- [ ] 多实例部署时速率限制共享
- [ ] 上传进度在服务重启后保持

### 3.5 [P-05] 文件列表分页与虚拟滚动

**当前状态**: 前端 `dashboard.html` 使用静态 HTML 渲染文件列表，无分页。

**改进方案**:
```
后端：
- API 增加 page/page_size 参数
- 返回 total 和 has_more 字段
- 支持游标分页 (cursor-based)

前端：
- 引入 Intersection Observer 实现无限滚动
- 或使用虚拟滚动（大量文件时）
```

**验收标准**:
- [ ] 10000+ 文件时列表加载 < 500ms
- [ ] 滚动流畅无卡顿
- [ ] 搜索过滤即时响应

## 6. 代码质量与架构

### 6.1 [C-01] 结构化错误类型

**当前状态**: 错误处理使用字符串 `map_error()` 和 `api_error()` 函数。

**改进方案**:
```python
# 使用异常层次结构
class TelegramDriveError(Exception):
    def __init__(self, code: str, message: str, status_code: int = 500):
        self.code = code
        self.message = message
        self.status_code = status_code

class NotFoundError(TelegramDriveError):
    def __init__(self, resource: str, id: str):
        super().__init__("NOT_FOUND", f"{resource} {id} not found", 404)

class AuthenticationError(TelegramDriveError): ...
class RateLimitError(TelegramDriveError): ...
class StorageError(TelegramDriveError): ...
class TelegramError(TelegramDriveError): ...
```

**验收标准**:
- [ ] 所有 API 错误使用统一异常类
- [ ] 异常自动映射到 HTTP 状态码

### 6.2 [C-02] 依赖注入解耦

**当前状态**: 路由函数通过 `request.app.state.app` 获取全局状态。

**改进方案**:
```python
# 使用 FastAPI Depends 实现依赖注入
from fastapi import Depends

async def get_state(request: Request) -> AppState:
    return request.app.state.app

async def get_storage(state: AppState = Depends(get_state)) -> Storage:
```
