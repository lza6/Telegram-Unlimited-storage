Web 控制台含上传、文件列表、分享与传输模式；深度管理请用桌面端。

服务状态

首次使用（Bot 模式 3 步）
  1. 在 .env 填写 TG_BOT_TOKEN
  2. 填写私有频道 TG_STORAGE_CHANNEL_ID（机器人需为管理员）
  3. 下方上传小文件测试；成功响应应含 /d/signed 或分享链接
首次使用（User 模式）
  1. 打开 Telegram 登录 完成会话绑定
  2. 返回本页确认状态为「应用模式 已就绪」
  3. 在文件列表可使用搜索；批量移动需 User 模式
