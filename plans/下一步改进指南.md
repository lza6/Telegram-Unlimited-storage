## 2. 升级哲学与原则

### 2.1 核心原则

| 原则 | 说明 |
|------|------|
| 🎯 **非重构，而是升级** | 不动现有架构骨架，在已有实现上增强 |

| ✅ **全链路闭环** | 每个改动必须经过：测试 → 构建 → 运行验证 |
| 🧹 **清理旧产物** | 升级后清理屎山代码、旧版本残留、死代码 |
| 🧪 **100% 测试覆盖** | 新增代码必须配套真实测试套件 |
| 🚀 **性能优先** | 每次改动必须考虑性能影响 |
| 🔒 **安全第一** | 安全问题必须立即修复或隔离 |

### 3.5 [P1-03] Telethon connect 重试逻辑

**文件**: `backend/app/telegram_state.py:233-241`

**问题**: `connect()` 仅调用一次，网络不稳定时直接抛异常。

**修复**:
```python
async def connect(self) -> TelegramClient:
    async with self._lock:
        if self.client is not None and self.client.is_connected():
            return self.client
        if self.client is None:
            self.client = self._build_client()
        last_exc: Optional[Exception] = None
        for attempt in range(self._CONNECT_RETRIES + 1):
            try:
                await asyncio.wait_for(
                    self.client.connect(),
                    timeout=self._CONNECT_TIMEOUT,
                )
                return self.client
            except Exception as exc:  # noqa: BLE001
                last_exc = exc
                if attempt < self._CONNECT_RETRIES:
                    logger.warning("connect attempt %d failed: %s", attempt + 1, exc)
                    await asyncio.sleep(1.0 * (attempt + 1))
        raise last_exc or ConnectionError("connect failed")
```

**验收标准**:
- [ ] 瞬时网络抖动自动重试
- [ ] 日志显示重试次数
- [ ] 最终失败返回有意义的错误

### 4.1 [M-01] SQLite 连接池化 / 异步化

**文件**: `backend/app/storage.py`

**问题**: 当前使用 `threading.Lock()` 串行化所有数据库操作，高并发下成为瓶颈。

**解决方案**: 引入 aiosqlite 异步化：
```python
import aiosqlite

class AsyncStorage:
    def __init__(self, db_path: Path) -> None:
        self._db_path = db_path
        self._pool: Optional[aiosqlite.Connection] = None
    
    async def initialize(self) -> None:
        self._pool = await aiosqlite.connect(str(self._db_path))
        self._pool.row_factory = aiosqlite.Row
        await self._pool.execute("PRAGMA journal_mode=WAL")
        await self._pool.execute("PRAGMA foreign_keys=ON")
    
    async def list_shares(self) -> list[dict[str, Any]]:
        async with self._pool.execute(
            "SELECT * FROM shared_links ORDER BY created_at DESC"
        ) as cur:
            return [dict(row) async for row in cur]
```

**验收标准**:
- [ ] 并发查询不再阻塞
- [ ] WAL 模式充分利用
- [ ] 现有 API 完全兼容

### 4.3 [M-03] 审计日志系统

**文件**: 新增 `backend/app/audit.py`

**问题**: 缺少安全审计日志，无法追踪敏感操作。

**解决方案**:
```python
"""审计日志模块 — 记录所有安全相关操作"""

from dataclasses import dataclass, field
from datetime import datetime
from enum import Enum
import json
from pathlib import Path

class AuditEvent(Enum):
    AUTH_SUCCESS = "auth.success"
    AUTH_FAILURE = "auth.failure"
    FILE_UPLOAD = "file.upload"
    FILE_DELETE = "file.delete"
    FILE_DOWNLOAD = "file.download"
    SHARE_CREATE = "share.create"
    SHARE_ACCESS = "share.access"
    SETTINGS_CHANGE = "settings.change"

@dataclass
class AuditLog:
    event: AuditEvent
    actor: str
    target: str
    metadata: dict
    timestamp: datetime = field(default_factory=datetime.utcnow)
    
    def to_json(self) -> str:
        return json.dumps({
            "event": self.event.value,
            "actor": self.actor,
            "target": self.target,
            "metadata": self.metadata,
            "timestamp": self.timestamp.isoformat(),
        })

class AuditLogger:
    def __init__(self, log_path: Path) -> None:
        self._path = log_path
        self._path.parent.mkdir(parents=True, exist_ok=True)
    
    def log(self, event: AuditEvent, actor: str, target: str, **metadata) -> None:
        entry = AuditLog(event=event, actor=actor, target=target, metadata=metadata)
        with open(self._path, "a") as f:
            f.write(entry.to_json() + "\n")
```

**验收标准**:

from dataclasses import dataclass
from pathlib import Path

@dataclass
class FileCategory:
    name: str
    confidence: float
    tags: list[str]

def classify_file(filename: str, mime_type: str) -> FileCategory:
    """基于文件特征的智能分类"""
    ext = Path(filename).suffix.lower()
    
    category_rules = {
        "document": {
            "extensions": [".pdf", ".doc", ".docx", ".txt", ".md"],
        },
        "image": {
            "extensions": [".jpg", ".png", ".gif", ".webp", ".svg"],
        },
        "video": {
            "extensions": [".mp4", ".mkv", ".avi", ".mov"],
        },
        "audio": {
            "extensions": [".mp3", ".wav", ".flac", ".aac"],
        },
        "archive": {
            "extensions": [".zip", ".rar", ".7z", ".tar", ".gz"],
        },
    }
    
    for category, rules in category_rules.items():
        if ext in rules["extensions"]:
            return FileCategory(
                name=category,
                confidence=0.9,
                tags=[ext[1:]],
            )
    
    return FileCategory(name="other", confidence=0.5, tags=[])

### 9.2 [AI-02] 重复文件检测

**解决方案**:
```python
"""基于内容哈希的重复文件检测"""

import hashlib
from typing import Optional

class DuplicateDetector:
    def __init__(self, storage: Storage, telegram: TelegramState) -> None:
        self._storage = storage
        self._telegram = telegram
    
    async def find_duplicates(self, folder_id: Optional[int]) -> list[list[dict]]:
        """查找重复文件"""
        files = await self._telegram.list_files(folder_id)
        hash_to_files: dict[str, list[dict]] = {}
        
        for file in files:
            file_hash = await self._compute_hash(file)
            hash_to_files.setdefault(file_hash, []).append(file)
        
        return [files for files in hash_to_files.values() if len(files) > 1]
    
    async def _compute_hash(self, file) -> str:
        """计算文件内容哈希"""
        message = await self._telegram.get_message(file.folder_id, file.id)
        content = b"".join([
            chunk async for chunk in self._telegram.iter_download(message)
        ])
        return hashlib.sha256(content).hexdigest()
```
