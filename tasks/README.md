# RIPER-5 任务记录目录

本目录存放 **按次执行** 的任务跟踪文件，与 `docs/planning/` 中的长期路线图分离。

## 命名规范

```
tasks/riper5_YYYYMMDD_HHMMSS.md
```

示例：`tasks/riper5_20260601_143000.md`

## 何时创建

- 使用严格 RIPER-5 协议（Research → Innovate → Plan → Execute → Review）实施 [下一步改进指南.md](../docs/planning/下一步改进指南.md) 的某一阶段或多阶段时
- 需要可追溯决策、阶段门禁、用户确认「继续」时

## 标准模板

```markdown
# RIPER-5 任务执行记录

**任务ID**: riper5_YYYYMMDD_HHMMSS  
**创建时间**: YYYY-MM-DD HH:MM:SS  
**用户需求**: （例：按指南阶段 1 补测试覆盖率）

## 1. 研究分析
### 1.1 需求分解
### 1.2 代码分析
### 1.3 架构分析
### 1.4 约束识别

## 2. 方案探索
### 2.1 方案列表
### 2.2 评估矩阵
### 2.3 权衡分析

## 3. 执行计划
### 3.1 选定方案
### 3.2 步骤分解
### 3.3 执行顺序
### 3.4 质量检查点

## 4. 执行日志
### 4.1 执行记录
### 4.2 问题处理
### 4.3 质量检查（附 §六 门禁命令输出摘要）

## 5. 回顾总结
### 5.1 成果验证
### 5.2 变更摘要
### 5.3 质量报告
### 5.4 经验总结
```

## 与规划文档的关系

| 文档 | 角色 |
|------|------|
| `docs/planning/下一步改进指南.md` | 长期路线图（v2→v3），不按次删除 |
| `docs/planning/代码库规格.md` | 代码库快照，大版本后更新 |
| `tasks/riper5_*.md` | 单次实施会话的工作记忆，可归档 |

## 周报（可选）

完成大任务后，可在 `tasks/weekly.md` 追加：

```markdown
- **YYYY-MM-DD**: [riper5_YYYYMMDD_HHMMSS](./riper5_YYYYMMDD_HHMMSS.md) — 一句话成果。
```
